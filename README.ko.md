# lavela-preflight (한국어)

AI로 만든 앱이나 게임을 **인터넷에 올리기 전에** 돌려 보는, 무료이고 **읽기 전용**인 점검 도구입니다.

클로드 코드에서 명령어 하나를 치면, 올릴 때 가장 자주 터지는 문제를 프로젝트에서 찾아서 알려 줍니다. 코드에 남은 키, 아무나 열 수 있는 데이터, 서버에서만 깨지는 설정, 나중에야 알게 되는 에러, 갑자기 커지는 요금, 다시 올리면 사라지는 데이터 같은 것들입니다. 찾은 것과 확인하지 못한 것을 함께 알려 주고, 파일은 절대 고치지 않습니다.

> AI가 도와주는 점검이며 보안 감사가 아닙니다. 놓치는 것이 있을 수 있으니 중요한 앱은 사람의 확인을 한 번 더 받으세요.

## 설치

```bash
claude plugin marketplace add ym2629/lavela-preflight
claude plugin install lavela-preflight@lavela
```

## 사용법

프로젝트 폴더에서 클로드 코드를 열고 아래 명령을 입력합니다.

| 명령 | 점검하는 것 |
|---|---|
| `/lavela-preflight:all` | 1~7번을 순서대로 돌리고 가장 중요한 5가지를 정리 |
| `/lavela-preflight:secrets` | 코드, 브라우저에 내려가는 코드, git 기록에 남은 키와 비밀번호 |
| `/lavela-preflight:access` | 로그인 없이 열리는 곳, 남의 데이터를 볼 수 있는지, 화면에서만 숨긴 관리자 기능, 데이터베이스 접근 규칙 |
| `/lavela-preflight:server-ready` | 빌드·시작 명령, 포트, 필요한 설정(이름만), localhost 주소, 개발용 설정 |
| `/lavela-preflight:errors` | 문제가 생겼을 때 내가 알 수 있는지 (기록, 상태 확인, 알림) |
| `/lavela-preflight:cost` | 요금이 갑자기 커질 수 있는 곳 (예: 로그인 없이 쓸 수 있는 AI 호출) |
| `/lavela-preflight:data` | 데이터가 어디에 저장되는지, 재시작·재배포 후 남는지, 백업과 되돌리기 |
| `/lavela-preflight:post-launch` | 올린 직후 30분 동안 확인할 목록 (프로젝트에 맞춰 작성) |
| `/lavela-preflight:payments-privacy` | 선택: 결제와 개인정보 (키 종류로 테스트/실제 구분, 웹훅, 정책 페이지). 법률 조언 아님 |

## 하는 일과 하지 않는 일

- **읽기만 합니다.** 파일을 고치거나 만들거나 지우지 않고, 빌드·설치·마이그레이션을 실행하지 않으며, 어떤 서버에도 연결하지 않습니다.
- **비밀 값을 출력하지 않습니다.** 키와 비밀번호는 파일 이름과 종류만 알려 줍니다. `.env` 파일은 열지 않고 이름만 확인합니다.
- **한계를 숨기지 않습니다.** 코드에서 확인한 것과 사람이나 대시보드에서 확인해야 하는 것을 나눠서 보여 줍니다.
- **이 플러그인이 데이터를 보내지 않습니다.** 훅, MCP 서버, 자체 네트워크 접근이 없습니다.

## 만든 곳

[lavela](https://lavela.dev) 팀이 만들었습니다. lavela는 AI 에이전트가 GitHub 저장소의 앱을 서버에 올리고 상태를 알려 주는 서비스입니다. 이 플러그인은 어떤 프로젝트에서도 쓸 수 있고 lavela가 필요하지 않습니다. 라이선스는 MIT입니다.
